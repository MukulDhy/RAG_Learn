Status Monitor

Topic: CL097

Purpose

The Status Monitor feature allows you to see a realtime representation of Rung status. Graphical highlights identify bit-level devices that are ON or OFF as well as Data Values of program registers. The PLC must be connected for Status Monitor to be available.

Accessing the Status Monitor

Access the Status Monitor by selecting Monitor > Status Monitor from the Monitor Menu or from the Program tab of the Navigation Window, or use the Keyboard Shortcut, Ctrl + Shift + S.

Graphical Presentation of Rung Status
Bit-level Devices

Bit-level devices are highlighted when current is passed through the rung. When all Contact Area devices are ON, current will be passed to the Coil Area device.

Graphical Presentation of Rung Status
Data Registers

Data-type devices display current values when Status Monitor is turned ON.
