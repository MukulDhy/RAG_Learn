Override View

Topic: CL160

Description

With the Override View window, you can access All Memory Addresses that are set to the Override status. The Override View window can be accessed from the Program Tab of the Navigation Window or the Monitor Menu located on the Main Menu.

In addition, the Override View window can be used to Write values in the Memory Addresses of the CLICK PLC using the same process used for the Data View. Both uses are described below.

Note: You can edit the Override status in the Override View window. However, when the Override View window is closed and then reopened, only those Memory Addresses currently in Override will be displayed. This is true even if an Override is set in the Override View window, if the Override status is disabled on Data View, it will no longer display that Memory Address in the Override View window when reopened.

Override View Window

When the Override View window opens, only the current Overrides set in the CLICK PLC are displayed as shown below.

   

1 Fill Down: Select a Memory Address by clicking in its cell and click Fill Down button to add consecutive Memory Addresses to the table in subsequent rows. Each click increments by one. (Shortcut Key: Ctrl + Return)
  
Example: Click Memory Address X003 and click the Fill Down button. Memory Address X004 is inserted just after X003. Click the  Fill Down button again, Memory Address X005 is inserted after X004.

   

2 Write All New Values: Writes All New Values into the CLICK PLC. (Shortcut Key: Ctrl + W). The Note shown below will display. Click Yes to continue and the Override should take place soon after.

3 View Override: This feature is not modifiable from the Override View window. It always shows View Override selected because the Override View window is always on View Override mode.

4 Address: Double-click on the blank cell and type in a Memory Address, or click the cell and then click the Address Picker icon to open the Address Picker where you can browse the Memory Address table. You can also use the Fill Down button to enter consecutive Memory Addresses.

Note: Any Memory Address added and written using the Override View window will be removed if the Override View window is closed and reopened, unless the added Memory Address was on Override mode when the Override View window was closed.

5 Nickname: If the Memory Address has a Nickname, it is displayed in this column. If you want to add or change a Nickname, move the cursor to the Address column on the same row and click the Address Picker icon to open the Address Picker. In the Address Picker, click Edit Mode on the left bottom and type in the new Nickname.

6 Current Value: The Current Value held in the Memory Address is displayed. When the Current Values change, the Value is displayed in red.

7 New Value: You can change the status of each Memory Address by double-clicking the ON and OFF button. Make sure the Override Status for the Memory Address is ON. (See Item 9, Override Column for details.)

8 Write: Double-clicking the Write-to-PLC icon transfers the New Value to the CLICK PLC.

9 Override Column: The OVR button allows you to Enable or Disable the Override to the Memory Address. Double-click the OVR button to change the status of the Bit Memory Address manually by clicking the ON and OFF button in the New Value column.

10 Viewing Format: Because the Override feature can only be used for the Bit Memory Addresses, the Viewing Format is always Bit.

Note: A quick way to check if there are any Overrides active is to look at the Connection Status Toolbar to see if the Override message is displayed as shown below.
