CPU Built-in I/O Setup: Input Tab (Ethernet Analog CPU, Voltage Only Type)

Topic: CL219

Purpose

The CPU Built-in I/O Setup Input Tab dialog gives the user access to setup parameters that are available exclusively for the Built-in Inputs. When the Built-in Input Tab is selected, the Input settings options are displayed as shown below.

1 General: Selecting the General Tab displays the CPU Built-in I/O General options.

2 Output: Selecting the Output Tab displays the CPU Built-in, Output setup options.

3Input Range:Enter the maximum and minimum Input Range to scale in the range of 0-10V.

Scale Range Example

4 Scaled Range: Enter the maximum and minimum scaled values.

In the following example, the Input Range is set to 4.0 - 8.0V and the Scale Range is set to 0.0 - 100.0. This means input voltage 4.0V will be converted to 0.0 and input voltage 8.0V will be converted to 100.0. When input current is 6.0V, 50.00 will be entered in DF1.

5 Enable Range Limiter: By checking this option, the analog values that are outside of the Input Range will be adjusted to the minimum or maximum value of the Scale Range.

1. Enable Range Limiter is ON.

2. Enable Range Limiter is OFF.

6 Continue Address: If you want to assign continuous DF Memory Addresses to AD1 – AD4, please check this option.

7 Data Register: Enter a DF address to store the scaled analog value. In the CLICK PLC, all analog data are handled as floating point numbers. So you can select only DF Memory Addresses.

8 Resolution:The CLICK software automatically calculates the resolution of the scaled data according to the bit resolution of the analog input and the scaling setup, and display the value here.
