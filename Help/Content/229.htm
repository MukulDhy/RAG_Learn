Filter Input

Topic: CL229

Purpose

Click on the respective Input Filter selection to choose to set the specific Input to Filtered Input. Enter the Filter Time directly or click on the arrows to change the value in milliseconds. The valid setup range is 1 to 99 ms. When the Physical Input signal keeps its status for longer than the Filter Time, the status is copied to the Memory Address assigned to the Input.

1 Nickname: The nickname of the filter is displayed.

2 Use: Check this box to use a filter with your project.

3 Filter: Displays the milliseconds for the selected filter.

4 ms: Click up or down to adjust the milliseconds for the selected filter.
