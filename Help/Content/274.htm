MQTT Error Code List

Topic: CL274

The table provided below includes a list of the MQTT Errors along with causes, solutions, and other reference information. When an Error occurs for a Publisher or Subscriber, the Error Code can optionally be stored into a data register.

Error Code

Error Name

Category

Causes

Solutions

0

Success

No Error

  
  • The previous Publisher or Subscriber action was successful.

1

MQTT Server connection error

Error

Failed to connect to the MQTT server
  • Check that the Server IP or URL is correct.
  • Check that the Server Authentication credentials are correct.
  • Check that the port (Port1 or WLAN) status indicates that the port is ready to be used.
  • Check that the port (Port1 or WLAN) has been assigned a Default Gateway.
  • If using a Server URL, check that the port (Port1 or WLAN) DNS Server is correct and the port does not indicate an Error condition.

2

 Transmission Error

Error

 The Publisher is configured for QOS1 but no ACK was received from the Server.
  • Packet loss can trigger this error, retry the Publisher.
  • The Server may not support QOS1.

3

 Subscriber Ping Response Timeout

Error

 The Subscriber was connected to the Broker but the MQTT Ping Response was not received from the Broker.
  • Packet loss can trigger this error. The Subscriber Enable must be disabled and re-enabled.

4

 Broker closed TCP connection

Error

The Broker may close the TCP connection for many reasons including communication errors or timeouts.
  • Subscriber: the Subscriber Enable will need to be turned OFF and then ON again.
  • Publisher: retry the Publisher Enable bit, and check the Broker configuration that the current Username has permissions to publish to the configured Topics.
