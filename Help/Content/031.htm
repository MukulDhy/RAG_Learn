Undo

Topic: CL031

Description

The Undo Icon is located on the Edit Toolbar. The Undo Selection is available from the Edit Menu, located on the Main Menu.

The Undo selection allows the user to go back one step or more after taking an action or actions, such as copy, paste or delete. Undo must be used immediately following the action. For example, if you Cut a rung element and then decide you want to return it to its original position, click on Undo.

Note: The Undo and Redo functions save up to 20 levels of Undo's and Redo's.
