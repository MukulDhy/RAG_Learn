Reset Factory Default Tool

Topic: CL287

The CLICK Factory Default tool is installed with CLICK Programming Software v3.00 or later. It can be opened from the Start Menu of your PC.

Note: To downgrade from Firmware from v3.8 or higher to a Firmware below v3.8 you must use CLICK Factory Default Tool first.

In order to use the Factory Default tool, you must use a local USB connection.

Module Type: The Reset process is different for different PLC families. Select the Module Type

  • C2-x - CLICK PLUS series
  • C0-1x - Click Ethernet series
  • C0-0x - Click original series - This series is not supported by this tool. Instead, use the programming software Menu > PLC > Reset to Factory Default.
  • C2-NRED - CLICK PLUS Intelligent module for Node-RED
  • C2-OPCUA - CLICK PLUS Intelligent Module for OPC UA Server Communications

Com Port No: Select the COM port that coincides with the port on the PC connected to the PLC.

Warning: Keep in mind, all data in the PLC memory will be erased.

C2-x

To reset the C2-x series:

  • Must use a USB connection
  • Make sure the mode switch is in Stop position
  • Cycle power and select OK within 30 seconds

Note: The tool can be used when 24VDC power is supplied, or with the PLC in USB Low Power Mode. This means no power supply is attached and the PLC is powered only by the USB connection.

C0-1x

To reset the C0-1x series:

  • Must use a serial RS232 connection to the PLC. The EA-MG-PGM-CBL programming cable assembly will work well for this from your PC USB to the CLICK RS-232 port 1.
  • Current firmware must be version 3.00 or later
  • Make sure the mode switch is in Stop position
  • Cycle power and select OK within 30 seconds

C2-NRED/C2-OPCUA

To reset the C2-NRED or C2-OPCUA Intelligent Module:

  • Must use a USB connection
  • Make sure the mode switch is in Stop position
  • Cycle power and select OK within 120 seconds of the OK LED turning on

Note: The tool can only be used when 24VDC power is supplied.
