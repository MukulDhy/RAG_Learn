MQTT Payload Builder

Topic: CL270

Description

The MQTT Payload Builder dialog allows you to create the Payload text that will be published for each Topic.

Payload Builder

Static Text Message (Max 128 Characters)

From this field, you can compose the ASCII Text Message to be sent to the MQTT Broker. You can mix Text Messages, ASCII Codes, Memory Addresses and Discrete Messages in the ASCII Text Message.  This field allows up to 128 characters in the message.

  1. Text Message: Enter any static text. All text must be enclosed in double quotation marks. (e.g., “ABC”) 
  2. ASCII Code: Click the Embed ASCII Code button to pick an ASCII Code. ASCII Codes are displayed in the format of “$” + 2 digit Hex Code in this field. Please refer to the help topic ASCII Table for further details.
  3. Memory Address: Click the Embed Memory Address button to select a data register Memory Address and set its formatting for inclusion in the ASCII Text Message. The current value stored at that Memory Address at the time the message is sent to the MQTT broker will be included in the ASCII Text Message. Supported Memory Addresses: DS, DD, DH, DF, XD, YD, TD, CTD and SD.
  4. Discrete Message: Click the Embed Discrete Message button to configure a text string to be included based on the value of a discrete Memory Address.

 

Example:

Simulate

Click this button to open a dialog used to enter values to Simulate the Data in the Memory Addresses you Embedded in the ASCII Text Message.  Please refer to the help topic Static Message Simulate for details.

Possible Message Length:

The CLICK Software automatically calculates the Possible Message Length and displays it here.

 

Dynamic Text Message (Max: 128 Characters)

Select Dynamic Text Message to Send a Message stored in a series of Text Addresses.  Select the Text Address and the Number of Bytes using the Start Address and the Number of Bytes Browse Icon respectively.

 

Other Controls

Whether Static or Dynamic text is used, the following additional formatting options are available.

Termination Code: Click on the checkbox to select. The Termination Code fields for 1 Character and 2 Characters become active. Select the number of Characters to use and enter the ASCII Code in the field(s). Click on the ASCII Table button to display possible values and select from the table.

Byte Swap: Select the checkbox if Byte Swap will be used. If selected, the ALL and All But Null selections will become active. Click one of these methods to select it.
