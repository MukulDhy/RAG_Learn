Topic: CL304

CLICK PLUS Email Address Search Replace

Description

Replace is a tool that searches the Address Book for instances of the Search string and changes those to the Replace string. Replace can be used to change strings in the Name and in the Email Address. The Target Search can be limited to 3 different areas: Name, Account (before the @), Domain (after the @).

Replace Dialog Setup

Replace All: Will immediately perform the Replace for all instances.

Replace: Will immediately replace the text currently highlighted in Orange.

Search Next: Increments the Search through each found item in Yellow.

Note: Edits are not permanent until the Address Book is closed via the OK button. Canceling will abort any Edits and Replacements.
