Topic: CL317

Check Event Records

Purpose

This dialog allows you to check the various Records and Logs in the connected PLC. The dialog is only available while connected to a PLC. User Accounts, Allow List and Email Log are individually enabled in the project file and are not available in all CPU types. Audit Records is automatically enabled in all CPU types.
