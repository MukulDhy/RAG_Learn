Insert Row Before Cursor

Topic: CL119

Description

The Insert Row Before Cursor selection serves to create a new row before the current cursor position.

Example

In the following example, a new row will be created between Rung 2, Row 2 and Rung 2, Row 1.

Position the Cursor

Position the cursor in the desired location.

Click Insert Row Before Cursor

Select Edit > Insert > Insert Row Before Cursor.

Result

A new row has been inserted before the former Rung 2, Row 2. The former Rung 2, Row 2 is now Rung 2, Row 3, and the new row is Rung 2, Row 2.
