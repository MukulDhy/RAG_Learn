File Menu

Topic: CL017

Description

The File Menu is located on the Main Menu bar.  When the user clicks on the File Menu, a drop down menu opens as shown below. This drop down menu provides a list of command selections available. For more information on the selections available from the File Menu, click on the desired selection in the figure below.

Recent Projects

The File Menu keeps track of the Projects that were opened recently and displays them directly above the Exit selection as seen on the figure above. Click on any of the listed Projects to open that Project.
