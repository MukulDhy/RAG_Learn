Com Port 2 Setup Details

Topic: CL144

Description

The Com Port Setup Details dialog displays current settings of the selected Port. Com Port 2 is used for General Communications, acting as a Master or Slave, using MODBUS (RTU) or ASCII Protocol.  

Note: The Com Port setup is stored in the Flash EEPROM in the CLICK CPU module. This means you MUST download the user project into the CLICK PLC after you make any changes in the Com Port Setup.

Setup

1 Port: Select Port 2 from the drop down list to populate this dialog with current Port 2 setups.

2 Protocol: Port 2 supports MODBUS or ASCII Protocol. Select the Protocol appropriate for your application from the drop down list. If this option is grayed out, it means that one or more Receive/Send instructions are using this Com Port in the ladder program already. You can not change the Protocol until you delete those instructions.

3 Basic Configuration: This field covers the basic setup parameters necessary to use with this Com Port.

4 Node Address (1-247) [MODBUS Only]: If you use this Com Port as MODBUS Master, please enter a 1. If you use this Com Port as a MODBUS Slave, enter a MODBUS Node Address between 1 and 247. The Node Address needs to be unique in the network.

5 Baud Rate (bps): Select a Baud Rate from the drop down list to match the Baud Rate setup of the network.

6 Parity: Select the Parity Bit setup from the Odd, Even and None to match the Parity setup of the network.

7 Stop Bit: Select the Bit Length of the Stop Bit between 1 and 2 to match the Stop Bit setup of the network.

8 Communication Data (bit) [ASCII Only]: Select the Data Bit Length of the ASCII Data between 7 and 8 to match the Data BitLength setup of the external communication device.

9 Advanced Configuration: This field covers the Advanced Setup Parameters that are optional to use for Port 2.

10 Time-out Setting [MODBUS Only]: This parameter defines the Maximum acceptable response delay time from the MODBUS Slaves after the MODBUS Master sent a request to the Slaves. Select a Time-out Setting time between 100 ms and 30 sec from the drop down list. If the response delay time from a MODBUS Slave exceeds this setup, a Communication Error occurs and System Control Bit SC101 (Port 2 Error Flag) turns ON.

11 Character Time-out (2-1000 ms) [MODBUS Only]: This parameter defines the Maximum acceptable delay time between each Character (byte data) in the response from the MODBUSSlave. Enter a Character Time-out value between 2 and 1000 ms. If the delay time between each Character exceeds this setup, a Communication Error occurs and System Control Bit SC101 (Port 2 Error Flag) turns ON.

12 RTS ON Delay (0-5000 ms): With this setup parameter you can Delay the timing to start sending the Message through Com Port 2 after the RTS (Request To Send) signal turns ON.  Enter an RTS ON Delay value between 0 ms (No Delay) and 5000 ms.

13 RTS OFF Delay (0-5000 ms): With this setup parameter you can Delay the timing to turn ON the RTS (Request To Send) signal after the Message Sending to the external device is completed. Enter an RTS OFF Delay value between 0 ms (No Delay) and 5000 ms.

14 Response Delay Time (0-5000 ms) [MODBUS Only]: When this Port 2 is used to communicate as a MODBUS Slave, you can adjust the Delay time to response to the MODBUS Master. Enter a Response Delay Time between 0 ms (No Delay) and 5000 ms.

15 Wiring Details: Port 2 follows the RS-232C Communication Standard. Port 2 pin assignments are shown on the dialog.
