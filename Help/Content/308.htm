CLICK PLUS Email Subject Builder

Description

The Email Subject Builder provides several easy ways to create the subject text. The text can be Static, contain Register Values, and Discrete On/Off Text. In Dynamic mode the text can be fully customized and be variable length. The Subject has a maximum length of 128 bytes, or up to 8 Embedded Memory Addresses or Embedded Discrete Messages

Configuring the Email Subject Line

Static Text Message: The Email Subject can be defined here. The text can be Static, contain Register Values, and Discrete On/Off Text. The maximum length is 128 characters.

Dynamic Text Message: This option can be selected when the Email Subject was previously created in a TXT address block. Trailing Space and Null characters are allowed to terminate or fill the block length. The maximum length is 128 characters.
