MQTT Text View

Topic: CL275

Description

The MQTT Text View is a tool that you can use to Read and Write the Text of subscribed MQTT Topics.  Topics can be selected to display in this view by enabling the Add Item to MQTT Text View checkbox in the MQTTSubscriber Setup.

There are two operation modes:

  1. View Mode: You can Read the Text Strings in the TXT Memory Addresses. associated with subscribed MQTT Topics.
  2. Edit Mode: You can Read and change the Text Strings in theTXT Memory Addresses. associated with subscribed MQTT Topics.

The contents of the MQTT Text View window are stored automatically as a part of the CLICK project. You can Import and Export the contents, so they can be transferred to another CLICK project.

Note: Each CLICK project has only one MQTT Text View window.

View Mode

When the Edit button on the top left is not pressed, the MQTT Text View is in View Mode.  In this mode, you can Read the current Text Strings in the TXT Memory Addresses, but it is not allowed to change the Text Strings.

Edit: Clicking Edit puts the Text View Window into Edit Mode where you can change the Text Strings in the TXT Memory Addresses. (See Edit Mode below)

View (Current Text): Allows you to select the display format of the Current Text column in the table between the Text mode and the Hex mode (ASCII Code) or Both. The following is an example of each:

Note: There is a space between each character or Hex Number (ASCII Code).  This space is not stored in the TXT Memory Address. This is just to make it easier to Read the Text String in this column.

Note: When in Text Mode, a combination of two small characters like SP may be displayed in the Current Text column. This is a Control Code that cannot be displayed with just one ASCII character therefore, the Current Text column uses two characters to display one Control Code. A table with a list of all the available Control Codes is provided at the end of this topic. To view the Control Codes table now, click on the green text.

Start Address: Displays the Starting TXT Memory Address of the subscribed MQTT Topic.

Nickname: If the Starting TXT Memory Address has a Nickname, it is displayed in this column.

End Address: Displays the Ending TXT Memory Address of the subscribed MQTT Topic.

Length: This column displays the number of characters included in the payload from the Start Address to the End Address.

Current Text: This column displays the Text String included from the Start Address to the End Address. There are three modes to display the Text String, the Text Mode, Hex Mode (ASCII Code), and Both., as set by the View (Current Text) option above

MQTT Port Filter: Only subscribed MQTT Topics on the selected MQTT Ports will be displayed.

Export: You can Export the current contents of the MQTT Text View window as a Text View file. You can Import the file into a CLICK project to copy the contents later. Click the Export button and the Save As dialog will open. Type the File Name.  The File Name extension ctv will be added automatically.

Edit Mode

When the Edit button on the top left is pressed, the Text View is in Edit Mode.  In this mode, you can Read the current Text Strings in the TXT Memory Addresses and change them.

Edit: Clicking Edit puts the MQTT Text View Window into View Mode where you can only Read the Text Strings in the TXT Memory Addresses.  (See View Mode above)

View (Current Text): Allows you to select the display format of the Current Text column in the table between the Text mode and the Hex mode (ASCII Code) or Both. The following is an example of each:

Fill Remaining Area With: When the Next Text is shorter than the Current Text, the CLICK software will fill the remaining text area with one of the following three options:

  1. Null (00h): Fill the remaining text area with the Null Character (ASCII Code: 00h)
  2. Space (20h): Fill the remaining text area with the Space Character (ASCII Code: 20h)
  3. None(Not Write): No filling.

Example:

  1. Current Text = CLICK There are five characters.
  2. New Text = ADC There are three characters.

When the WriteIcon button is clicked, the CLICK Programming Software will send the following text string according to the selection for this option.

  1. Null (00h): ‘ADC’ + 2 Null Characters
  2. Space (20h): ‘ADC’ + 2 Space Characters
  3. None (Not Write): ‘ADC’ The Current Text will be ‘ADCCK’

Start Address: Displays the Starting TXT Memory Address of the subscribed MQTT Topic.

Nickname: If the Starting TXT Memory Address has a Nickname, it is displayed in this column.

End Address: Displays the Ending TXT Memory Address of the subscribed MQTT Topic.

Length: This column displays the number of characters included from the Start Address to the End Address.

Current Text: This column displays the Text String included from the Start Address to the End Address. There are three modes to display the Text String, the Text Mode, Hex Mode (ASCII Code), and Both. You can switch the display mode with the View (Current Text) option above the column. The following is an example of each:

Note: If there is any discrepancy with the text in the New Text column, they are displayed in Red.

Note: There is a space between each character or Hex Number (ASCII Code).  This space is not stored in the TXT Memory Address. This is just to make it easier to Read the Text String in this column.

New Text: You can type a Text String to replace the Current Text.  The number of characters that you have typed is displayed in the right of the cell in blue text. Click the Write Icon button to send the New Text to the CLICK PLC.

Note: If you have typed more characters than the value in the Length column, which is the size of the Current Text, the number of characters is displayed in red and the excessive characters are grayed out as shown below. You can still send the New Text to the CLICK PLC in this case. The CLICKProgramming Software will send only the valid number of characters to the CLICK PLC.

Write: Double-clicking the Write-to-PLC Icon  transfers the New Text to the CLICK PLC.

MQTT Port Filter: Only subscribed MQTT Topics on the selected MQTT Ports will be displayed.

Export: You can Export the current contents of the MQTT Text View window as a Text View file.  You can Import the file into a CLICK project to copy the contents later. Click the Export button and the Save As dialog will open. Type the File Name.  The File Name extension ctv will be added automatically.
