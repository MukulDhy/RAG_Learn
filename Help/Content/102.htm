Tile Horizontally

Topic: CL102

Description

If the opened Project includes Subroutine Programs and/or Interrupt Programs, you can Tile Horizontally the Programs to make them easier and quicker to see and select. Select Tile Horizontally from the Window Menu to stack the Programs in the Ladder Editor for better visibility.

Appearance

You can Tile Horizontally multiple Programs. Up to three have the unique characteristic of being Horizontal Tiles. If you Tile more than three programs, the appearance is the same as Tile Vertically. More than three programs are Tiled Horizontally and Vertically.

Note: The window with the Darker Blue Frame shown above represents the currently Active window.
