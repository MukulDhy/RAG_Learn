Forgotten Password

Topic: CL286

Note: All Ethernet-based CLICK PLC's with version 3.00 firmware or later ship from the factory with a default password.

Factory Default Password = click

When a project is created, the user is required to change the default password to a unique password first. The password is intended to protect and help minimize the risk of unauthorized access to the PLC in operation as well as protect the stored PLC project from being read or writing a new project to the PLC.

If the password stored in the PLC, is unknown or forgotten, there is no way to clear the password without resetting the PLC to its factory default state and losing the project stored in the PLC.

If the Password to connect to the PLC is forgotten the only option is to Reset Factory Default.
