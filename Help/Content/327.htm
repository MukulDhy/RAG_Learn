Topic: CL327

Add/Edit Allowed Port

To open a port on the C2-NRED interface, select "Port Management" to open the dialog below:

 

Protocol: Select either TCP or UDP protocol.

Port Number: Select a port number between 1 and 65535. Lower port numbers have dedicated functions. Several ports are required and always allowed, as shown below.

Always Allowed Ports
Always Allowed Ports
Port Protocol Description
53 UDP Domain Name Server (DNS)
68 UDP BootP (For DHCP)
123 UDP Network Time Protocol (NTP)
25425 UDP KOP/KOPS (CLICK Access)
1880 TCP Node-Red Editor
80 TCP HTTP
443 TCP HTTPS
ICMP ICMP PING

Comment: An optional comment to identify the port.

Note:The following special characters are not allowed:
% , <space> " < > ! # $ & ' ( ) * + - . / : ; = ? @ [ \ ] ^ ` { | } ~
