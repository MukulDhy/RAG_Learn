PTC Error Codes

Topic: CL188

The table provided below includes a list of the CLICK PLC PTC (Project Transfer and Communications) Error Codes along with Error Messages. When an Error or a Warning occurs, the Error Code is stored in the system data register SD1.

CLICK PTC Errors
Error Code Description Corrective Action
PTC-001 Cannot access comm port. The Port may not be present or another app may be using it.

It is always a good idea to start by installing the latest version of the CLICK programming software.

Ethernet Connection:

  • Open Windows Defender and ensure there is an inbound rule to enable TCP/IP and UDP communications and that allows access to all ports.
  • Ping the LAN side IP address of the router. If its value is higher than 175ms then you will need to increase the timeout time in the software.

Serial Connection:

  • Sometimes other programs like RSLinx control a port. Shut down RSLinx, reboot (do not restart other applications like RSLinx), try a different PC or try connecting using ethernet.
  • Open Device Manager and look for "Ports". Plug and unplug your CLICK to ensure the port is being recognized. If it's still not connecting, delete the port. Windows will automatically reinstall it the next time you connect.
  • Update your Windows driver using drivers found here: https://cdn.automationdirect.com/static/support/configfiles/EA-MG-PGM-CBL_drivers.zip.
PTC-002 COM Port Setting has failed.  
PTC-003 Protocol Setting has failed.  
PTC-004 COM Close has failed.  
PTC-005 Communication Error.
  • If using Modbus, make sure your Modbus server is enabled.
  • Upgrade to the latest Firmware.
PTC-006 The connected device is not a CLICK PLC.  
PTC-007 Cannot connect to the PLC.
  • Verify your cable/pinouts are correct according to the documentation (6 pin RJ-12).
  • Verify the RJ12 connector is in the serial port and not the ethernet port.
PTC-008 The PLC Mode cannot be changed.
  • Check the Error History for a detailed reason.
  • Verify Sys config setup matches the physical hardware.
  • Manually toggle the run mode to stop/run.
  • Cycle power on the PLC.
  • Common failure mode if I/O cards are swapped under power (Hot Swap). Try I/O cards one at a time to isolate which card is bad.
  • Make sure the project loaded and didn't have compile errors.
PTC-009 To change the PLC mode from this software, the PLC Mode switch must be in the RUN position. The Software cannot request RUN while the physical switch is in STOP.
PTC-010 Password Lock Failed.  
PTC-011 The CPU is found but is already attached to a different programming software.  
PTC-012 The PC and the target CLICK PLC must be in the same subnet to connect the CLICK Programming Software to the target CLICK PLC. Verify your IP and subnet and the CLICK IP and subnet. The subnet should be 255.255.255.0 and the last digit of the IP should not be the same. No device should have an IP starting with 169.
PTC-013 Timeout on attempting to connect to PLC.
  • There may be duplicate IP addresses in network. Open a command prompt and type "arp -a" to see all devices on your network or use a tool like "Advanced IP Scanner" to identify all devices in LAN to ensure you are picking a distinct IP.
  • Check Windows firewall to ensure Inbound ports aren't blocked.
  • Review you IP address and make sure the first 3 octets of the IP match.
  • If any IP address looks like 169.XXX.XXX.XXX, that indicates your DHCP server isn't assigning addresses and the devices on the network can't communicate. Restart your router and check its settings.
  • If connecting from outside a LAN verify your port number is 25425.
  • If using a VPN router, try entering the IP address of the VPN router in the PLC Connect Screen.
  • Try connecting with USB.
PTC-014 EtherNet/IP is enabled. Could not change to DHCP.  
PTC-015 DNS Server is enabled. Could not change to Use default fixed address.  
PTC-016 DNS Server automatically is enabled. Could not change to Use default fixed address or Use the following IP Address.  
PTC-017 Port IP Address changes are disabled. To enable edits, see Setup>Com Port Setup> Enable IP address to be changed from software.  
PTC-018 PLC mode cannot be changed in USB Low Power Mode. External 24V DC power must be provided for Run mode.  
PTC-019 Cannot log into PLC. There is already an active session detected with the PLC.  
PTC-020 Cannot access the comm port on the PC. The port may no longer exist or has changed state.
