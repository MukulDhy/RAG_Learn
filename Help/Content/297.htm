PTO Error Codes

Topic: CL297

The table provided below includes a list of the Pulse Train Output (PTO) Errors. These are available from the motion instructions: Home, Position Move, Velocity Move.

PTO Errors
Error Code Error Message
101 When the instruction is Disabled before the instruction operation is Complete. (Position Move and Home Instructions)
102 When an instruction for the same axis is being executed elsewhere.
103 When a limit switch input is detected.
104 When the target velocity is 0 when the instruction is enabled.
105 When the acceleration parameter is out of range. (1～100000)
106 When the deceleration parameter is out of range. (1～100000)
107 When the S-curve parameter is out of range. (1～100)
108 For Interpolated moves the Minimum Velocity of each used Axis must be configured as zero.
109 Home, when the Switch1/Switch2 events do not occur in order, or the Switch event occurred during ramping.
110 When the Homing Stop Distance is set to a negative value.
