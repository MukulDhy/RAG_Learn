Edit Toolbar

Topic: CL124

Description

The dockable Edit Toolbar provides one-click access to the more commonly used tools on the Edit Menu. Select any of the icons on the Edit Toolbar below for more information about that particular tool. The icons appear grayed out if they are not currently available.

Toggle the Edit Toolbar On or Off

From View Menu > Toolbar, toggle any of the dockable One-click Toolbars Off or On.
