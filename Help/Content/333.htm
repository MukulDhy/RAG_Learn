Topic: CL333

Node List Import

Description

A Node is a range of PLC Addresses (registers) that is included in the OPC UA message. The C2-OPCUA Module allows users to import a list of Nodes to simplify setup.

The Node List Import feature can import an external CSV file of:

  • Address(Start), the starting address of the CLICK register used in this node
  • Array Size, the number of addresses in the range used in this node
  • RW, the read-only (R) or read-write (RW) status of the addresses in this node

To ensure correct formatting, start with a CSV file exported using the Export Node Listfunction. The CSV file is easily read and edited using Excel or Notepad. The CSV file can be re-imported or shared with other project files. The file can contain up to 1024 rows of CLICK address ranges.

Note: The easiest way to begin a Node List CSV file is to first Export the existing Node List.

Setup

File Path: Select the folder where you have the CSV file.

Add, Merge or Delete Existing: Select the radio button for the desired import method.

  • Addwill add the imported nodes to the existing node list and will create duplicate nodes if an imported node already exists.

  • Merge will add the imported nodes to the existing node list, but will skip any nodes that already exist.

  • Delete will remove all of the existing nodes and replace them with the imported nodes.

Error if CSV is Open

If the CSV file is open in another program, you will receive an Error Message.
