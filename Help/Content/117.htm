Insert Rung Before Cursor

Topic: CL117

Description

The Insert Rung Before Cursor selection serves to create a new rung before the current cursor position.

Example

In the following example, a new rung will be created between Rung 1 and Rung 2.

Position the Cursor

The Cursor is positioned on Rung 2, Row 2, but it could be positioned anywhere on Rung 2.

Click Insert Rung Before Cursor

Select Edit > Insert > Insert Rung Before Cursor.

Result

A new rung has been inserted before the former  Rung 2. The former Rung 2, is now Rung 3, and the new rung is now Rung 2.
