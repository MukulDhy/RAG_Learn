Email Error Codes

Topic: CL309

The table provided below includes a list of the CLICK PLC Email Error Codes along with Error Messages and their Descriptions. When an Error or a Warning occurs, the Error Code is available in the Instruction.

CLICK Email Errors
Error Code (Decimal) Description Condition Corrective Action
0 Normal    
000x Email Instruction Errors
1 Email Instruction Error Exception Error An unknown error has occurred. Reload the project to the CPU using the latest programming software.
2 Email Instruction Disable Error Email Instruction was executed with the Email function disabled. Select Enable Email Client in Email Setup.
3 Address Type Error A value other than Static, Dynamic, Dynamic + Static was set in the Email Address. Prevented by input restrictions in the CLICK programming software.
4 Management Task Error Exception Error An unknown error has occurred. Reload the project to the CPU using the latest programming software.
5 Email is already Busy When another Email instruction is enabled while an Email is already in progress. Only one Email can execute at any time, wait for it to Complete before enabling another.
001x Email Parameter Errors
10 Sender Name Size Error The sender name size is larger than the maximum value. Prevented by input restrictions in the CLICK programming software.
11 Sender Email Address Size Error The sender email address characters is larger than the maximum value. Prevented by input restrictions in the CLICK programming software.
12 Port No Error The value of port No. is 0. Prevented by input restrictions in the CLICK programming software.
13 Account Size Error The number of account characters is larger than the maximum value. Prevented by input restrictions in the CLICK programming software.
14 Password Size Error The number of password characters is larger than the maximum value. Prevented by input restrictions in the CLICK programming software.
15 Email Address Book Name Size Error The address book name characters is larger than the maximum value. Prevented by input restrictions in the CLICK programming software.
16 Static Email Size Error The static email characters is larger than the maximum value. Prevented by input restrictions in the CLICK programming software.
01xx Email DNS Errors
101 DNS Error Domain resolution failed.

Can’t connect to DNS server.

  • Check the SMTP Email Server settings in Email Setup.
  • Check the Network Address Configuration settings in Com Port 1 Setup or Wireless LAN Port Setup.
  • Check the DNS Server settings in Com Port 1 Setup or Wireless LAN Port Setup.
  • Check the Wireless LAN Basic Configuration settings in Wireless LAN Port Setup.
102 DNS Setting Error There is a mistake in the DNS settings.
  • Check the SMTP Email Server settings in Email Setup.
