Show/Hide Toolbar

Topic: CL132

Description

The Show/Hide Toolbar consists of four buttons that hide or reveal different features in the Ladder Editor. In the off state (not revealed), the Show/Hide buttons appear without highlight.

All Show/Hide Buttons Off

The rung below was created for demonstration purposes. All Show/Hide Buttons have been turned off.

Only Nicknames On

Only the Nicknames button is highlighted.

Only Address Comments On

Only the Address Comments button is highlighted.

Only Rung Comments On

Only the Rung Comments button is highlighted.

Only Coil Area On

Only the Coil Area button is highlighted.

All Show/Hide Buttons On

All Show/Hide buttons are highlighted in this image.

Toggle the Show/Hide Toolbar
On or Off

 

From View Menu > Toolbar, toggle any of the dockable One-click Toolbars Off or On. If there is a check beside the name of the Toolbar, then it is turned on.
