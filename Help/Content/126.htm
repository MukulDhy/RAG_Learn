Setup Toolbar

Topic: CL126

Description

The dockable Setup Toolbar provides one-click access to the more commonly used tools on the Setup Menu. Select any of the icons on the Setup Toolbar below for more information about that particular tool. The icons appear grayed out if they are not currently available.

Toggle the Setup Toolbar On or Off

From View Menu > Toolbar, toggle any of the dockable One-click Toolbars Off or On.
