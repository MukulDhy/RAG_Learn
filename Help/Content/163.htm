Edge Contact

Topic: CL163

Shortcuts: Rising Edge = SHIFT + F2  / Falling Edge = SHIFT + F3

Definition

The Edge Contact turns ON when the related bit transitions from OFF to ON ( Rising Edge ) or ON to OFF ( Falling Edge ).

Setup

1  Bit Memory Address: The Edge Contact requires a Bit Memory Address. The Bit Memory Address can be typed directly into the Address field on the dialog or it can be selected from the Address Picker.

Click on the Browse Button to open the Address Picker.

2 Edge Type: Select Rising Edge or Falling Edge contact using the radio buttons on the dialog.
