Write Data into PLC

Topic: CL088

Description

Write Data Memory allows the user to send discrete or data values to the PLC using a CSV file as the source. Write Data Memory is available during Runtime or when the PLC is in Stop Mode, but the PLC must be Connected.

Select  Write Data Memory from the PLC Menu or the Navigation Window.

Open the Project Data File

Setup

1a Select Write Memory Type: Click the check boxes to select the Memory Types that you want to write to the PLC memory.

1b All button: Click the All button if you want to overwrite the current values of all available Memory Types.

Note:System Memory values are not available, nor are the registers XD or YD, although the full range of X an Y memory addresses are accessed when you check those boxes.

Caution: Overwriting values in the PLC memory can cause a significant change in control behavior. It is the user's responsibility to insure the safety of such a change.

2 Write button: Click the Write button to load the values from the CSV file to the PLC memory.

3 File Select button: Click the File Select button to return to the Open dialog.
