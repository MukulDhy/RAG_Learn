PLC Toolbar

Topic: CL128

Description

The dockable PLC Toolbar provides one-click access to the tools on the PLC Menu. Select any of the icons on the PLC Toolbar below for more information about that particular tool. The icons appear grayed out if they are not currently available.

Toggle the PLC Toolbar On or Off

From View Menu > Toolbar, toggle any of the dockable One-click Toolbars Off or On. If there is a check beside the name of the Toolbar, then it is turned on.
