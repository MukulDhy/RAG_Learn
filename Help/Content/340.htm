Update Intelligent Module Firmware

Topic: CL340

 

Select C2-Intelligent Mode

Firmware for the C2-NRED and C2-OPCUA modules can be updated over a local wired connection (Ethernet or USB) or from an SD card.

Select your update method. Either method will require a local connection between the PC and the PLC.

Firmware in the Intelligent modules cannot be updated in USB Low Power Mode. The CPU must be powered by 24 VDC.

 

Connect to C2-Intelligent Module

Select Ethernet or USB as the connection method between your PC and the C2-Intelligent module.

Run the Connection Test to verify the connection before proceeding with the firmware update.

 

C2-Intelligent Network Setup

If you need to change Ethernet settings temporarily for the firmware update, click the Setup button, select an adapter and edit the settings.

 

Review Settings

Check the connection settings that will be used for the firmware update, then click Start to proceed.
