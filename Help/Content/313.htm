Topic: CL313

Allow List Export to CSV File

Description

The Export Allow List feature allows the user to create an external CSV file of:

  • IP/MAC Address, “IP” is the IP Address table, “MAC” is the MAC Address table
  • Type, can be “Single”, “Range”, or “Subnet”
  • Start Address, the single or starting address
  • End Address, only used for Type “Range” rows
  • Subnet Mask, only used for Type “Subnet” rows

The CSV file is easily read and edited using Excel or Notepad. The CSV file can be re-imported or shared with other project files. The file can contain up to 32 rows of IP addresses, and up to 32 rows of MAC addresses.

 

Setup

Save in: Select the folder where you want to save the Allow List.

File Name: Name the CSV file and click OK.
