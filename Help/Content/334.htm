Topic: CL334

Node List Export to CSV File

Description

A Node is a range of PLC Addresses (registers) that is included in the OPC UA message. The C2-OPCUA Module allows users to export a list of Nodes to simplify setup or document a system.

The Node List is exported as a CSV file containing:

  • Address(Start), the starting address of the CLICK register used in this node
  • Array Size, the number of addresses in the range used in this node
  • RW, the read-only (R) or read-write (RW) status of the addresses in this node

The CSV file is easily read and edited using Excel or Notepad. The CSV file can be re-imported or shared with other project files. The file can contain up to 1024 rows of CLICK address ranges.

 

Setup

Save in: Select the folder where you want to save the Allow List.

File Name: Name the CSV file and click OK.
