Embed Discrete Message

Topic: CL276

Description

Embed Discrete Message selects one of two possible text messages to output, based on the value of a discrete Memory Address.

Embedded Address: Select a memory address used to control the message. Any address with a BIT data type may be selected.

Discrete Message: Enter text strings to be returned when the binary value is ON and OFF. Each string can be a maximum of 24 characters long.
