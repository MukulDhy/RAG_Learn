CPU Built-in I/O Setup: General Tab (Basic and Standard CPU)

Topic: CL065

Description

The CPU Built-in I/O Setup dialog, General tab, identifies the CPU and summarizes the current settings for Built-in Inputs and Outputs. It also serves as an access point to the Input and Output setup dialogs when you click on the Input or Outputtabs.

Setup

Open the CPU Built-in I/O Setup dialog from the Setup Menu.

1General Tab: The General tab on the CPU Built-in I/O Setup dialog displays the currently configured CPU module.

2 Input Tab: Selecting the Input tab displays the CPU Built-in Inputs setup options.  To learn more about Input setup, click on the green text.

3 Output Tab: Selecting the Output tab displays the CPU Built-in Outputs setup options.

4 CPU Type: Displays the Part Number of the currently configured CPU Module.

5 I/O: This column displays the available I/O points for the current CPU Module.

6 Type: This column displays the Type of Input or Output for the each respective I/O.

7 State: This column displays the current State for each respective I/O.

8 Description: This column displays a Description of the I/O only if any has been provided.
