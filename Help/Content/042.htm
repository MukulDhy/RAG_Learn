Insert Menu Selection Purpose

The Insert Selection on the Edit Menu provides six handy ways to add space within the Ladder Program to add Contacts, Coils, or Box Instructions. The six versions of the Insert command each add one of the following:

  • Additional space for a parallel rung
  • An additional rung
  • Additional space along a rung

Each of these versions of the Insert command can be used Before the Cursor Position or After the Cursor Position.
