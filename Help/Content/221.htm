High Speed Input Configuration

Topic: CL221

Purpose

The High Speed Input Configuration dialog displays the available Inputs and Outputs which are capable of High Speed operations. Inputs and Outputs that have been assigned an operation can be selected and then edited or deleted.

Compatibility

The following CLICKCPUs are capable of high-speed I/O.

Setup

1 Inputs: Only Inputs which are capable of High Speed operation are listed here. Different CPU part numbers have different available features.

2 Outputs: Only outputs which are capable of High Speed operation are listed here. Different CPU part numbers have different available features.

3 Edit: Select an Input or Output above then click Edit to make changes to that operational mode.

4 Delete: Select an Input or Output above then click Delete to remove the operational mode.

5 High Speed Count:Configure a Counter for: Up, Down, Up/Down, Pulse/Direction, Quadrature.

6 Interval Measurement: Configure a Timer Measurement of a Single or Dual Input Signal.

7 Duration Measurement: Configure a Timer Measurement of a Pulse Width Signal.

8 Frequency Measurement: Configure a counter for Hz or RPM.

9 External Interrupt: Configure a Discrete Input to trigger an Interrupt Program.

10 Pulse Catch: Configure a Discrete Input to see an Input Pulse that is shorter in duration than the current scan time.

11 Filter: Configure a Discrete Input to filter pulses shorter than a filter time.
