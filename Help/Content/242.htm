Using CLICK as Remote I/O

Topic: CL242

When using the CLICK PLC as Remote I/O to a Modbus Master or an EtherNet/IP Scanner, the state of the Outputs during error conditions must be considered. By default, the Outputs will remain in their last commanded state. Your process may require a fault state for these Outputs.

Modbus RTU and Modbus TCP

For using with Modbus Masters, each Slave port has a system timer, see System Data Registers, which represents the elapsed time since the last good Modbus transaction. A simple Compare instruction can be used to detect this fault condition and update the Outputs to known states with a Reset instruction.

Use these System Data Registers to monitor elapsed time:

  • SD41 _Port1_No_Comm_Time
  • SD51 _Port2_No_Comm_Time
  • SD61 _Port3_No_Comm_Time
  • SD214 _WLAN_No_Comm_Time

Example using the Port 1 Comm Timer to reset CLICK Outputs

Implicit Messaging

EtherNet/IP

For using with EtherNet/IP Implicit Class 1 (I/O) Scanners, there are System Control Relays which indicate a healthy connection and the state of the Scanner. A simple Normally Closed Contact can be used to detect this fault condition and update the Outputs to known states with a Reset instruction. (Note: Not all Scanners will include the Run/Stop status header.)

Also, in the EtherNet/IP Adapter setup there is an option to Clear or Hold the last data state on a Network Error. This feature is specific to Implicit Class 1 connections only.

Use these System Control Relays, or select the Clear option for a Network Error option:

  • SC111 _EIP_Con1_ConOnline
  • SC113 _EIP_Con1_Originator_Run
  • SC114 _EIP_Con2_ConOnline
  • SC116 _EIP_Con2_Originator_Run

Example using an EtherNet/IP System Control Relay to reset CLICK Outputs

Explicit Messaging

For using with EtherNet/IP Explicit Class 3 Clients, each connection has a system timer, see System Data Registers, which represents the elapsed time since the last good Explicit Message transaction. A simple Compare instruction can be used to detect this fault condition and update the Outputs to known states with a Reset. Instruction.

Use these System Data Registers:

  • SD108 _EIP_Con1_No_Comm_Time
  • SD114 _EIP_Con2_No_Comm_Time

Example using the EIP Connection 1 Comm Timer to reset CLICK Outputs
