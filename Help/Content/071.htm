Add New Interrupt

Topic: CL071

Description

Interrupt Programs are created and named using the New Interrupt Program dialog, which is accessed from the Program Menu, by clicking on the Interrupt icon on the Setup Toolbar,  or by using the Ctrl + I keyboard shortcut. You can have up to 986 Subroutine Programs in a CLICK project.

New Interrupt Program Dialog

Create an  Interrupt Program using this dialog. The name can be a maximum of 24 characters long. Click OK to create the Interrupt Program and open the Ladder Editor to the new program.

Quick Guide

Before the Interrupt Program opens, first time users of CLICK Interrupts will encounter the Quick Guide for Interrupts, which contains important information about Interrupts.

  • A Interrupt Program must have at least one Return instruction to go back to the Main Program.
  • If an Interrupt Program needs to access discrete I/O, select "Immediate" when inserting the instructions in the program.
  • The PLC must be in Run Mode to call an Interrupt Program.
  • It is not allowed to call a Subroutine from an InterruptProgram.
  • The END instruction cannot appear in an Interrupt.  An END instruction is required in the Main Program.

Note: The background color of the Interrupt Program is different from the Main Program or Subroutine Programs to alert the programmer that the Interrupt Program is the active program. To customize the colors of the Ladder Editor, look at  Software Setup Color.

Switch Between Programs

To return to the Main Program, use the Window Menu and select Main Program. Also visit the Window Menu to Tile or CascadeProgram Windows.
