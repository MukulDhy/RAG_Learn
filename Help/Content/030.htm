Edit Menu

Topic: CL030

Description

The Edit Menu is located on the Main Menu. When the user clicks on the Edit Menu, a drop down menu opens as shown below. The Edit Menu provides a list of commands used for editing the Ladder Program.

For more information on the Edit Commands, click on the desired selection displayed on the Edit Drop Down Menu figure shown below.

 

Right Click in Ladder Editor

Another convenient way to access the Edit tools is by right clicking in the Ladder Editor. You can Cut, Copy, Paste or Insert a Rung or Row or Delete a Row.
