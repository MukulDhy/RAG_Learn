Delete

Topic: CL036

Description

The Delete selection from the Edit Menu provides a means for the user to Delete one or more selected items.

Selecting Delete will permanently remove the item. This item IS NOT placed on the clipboard. However, if the Delete action was accidental, the user may try to recover using the Undo selection available on the Edit Toolbar or by selecting Undo from the Edit Menu.
