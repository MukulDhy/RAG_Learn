Line Icon and Menu Selection Purpose

The Line icon is located on the Edit Toolbar and the Line menu selection is available from the Edit Menu. The Edit Menu is located on the Main Menu, as shown on the figure below. There is also a Keyboard Shortcut to activate the Line Tool.

The Line Tool is used in the Ladder Editor to:

  • Create Parallel Rungs
  • Extend Broken Rungs where rung elements were Deleted
  • Extend Horizontal Rungs where Resets, etc., are required by Coil Devices

Edit Box

Selection of the Line Tool converts the Edit Box to one or more Blue Arrows.

Blue Arrows

Click on the Blue Arrow that points in the direction you want to extend the line.

Note: While the Line Tool is in use, the cursor will toggle between a Pencil Cursor and a Hand Cursor. Hovering over the Blue Arrow will cause the pencil to change to a hand. While the hand cursor is visible, you can select any available blue arrow to extend the rung in the direction of the arrow.

Note: You may also use the CTRL + one of the Arrow Keys to Draw a Line. For example, when a NO Contact has been set on the left side of the rung, just press CTRL + an Arrow Right Key to extend the Line to the Right.
