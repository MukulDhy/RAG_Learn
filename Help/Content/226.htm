Frequency Measurement

Topic: CL226

Purpose

The Frequency Measurement is selectable for either Hz or RPM. Hertz is the number of pulses counted during one second. The value provided is the median of the five previous edge interval times converted to frequency. The cutoff frequency is 0,5 Hz, which is rounded in the Integer Register as 1Hz. When pulses stop, the measurement window continues for two seconds before 0Hz is reported into the Register. RPM is the number of revolutions during one minute.

1 Name: This text is used to Prefix Nicknames of addresses used by this configuration.

2 Assign Nicknames automatically: Nicknames can be assigned to each address automatically. If you want to manage the Nicknames manually then disable this feature.

3 Current Frequency: This is the Accumulator register of the Frequency.

4 Pulse Input: The Input type can be either Single Input, or Quadrature
.

  1. Single Input

  2. Quadrature

5 Pulse Input Bit: You can use only the CPU Built-in discrete inputs which are designated for high speed. Inputs cannot be shared by different high speed functions.

6 Frequency Unit: Select either Hz or RPM as the measured units.
