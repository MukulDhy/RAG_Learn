Com Port 1 Setup Details

Topic: CL143

Description

The Com Port Setup Details dialog displays current settings of the selected Port. Com Port 1 is used for programming and maintenance functions, exclusively, using MODBUS (RTU) protocol.

Setup

1 Port: Select Port 1 from the drop down list to populate this dialog with current Port 1 setups.

2 Protocol: Port 1 is a dedicated slave port used for programming and maintenance mainly. The Protocol supported by Port 1 is fixed and, therefore, grayed out.

3 Basic Configuration: The current Port 1 Basic Configuration is displayed.

4 Advanced Configuration: The Advanced Configuration settings are displayed but cannot be changed for Port 1.

5 Wiring Details: Port 1 follows the RS-232C Communication Standard.
