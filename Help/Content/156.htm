Creating Parallel Rungs

Topic: CL156

Create Parallel Rung

Parallel Rungs are easy to create using the Line Tool.

Example: You have created a line of logic, but you need to add one or more contacts in parallel with the contacts in first rung. Select the Line icon from the Edit Toolbar or select Line from the Edit Menu. Using the Line Tool, click on the rung where you want to create a vertical segment.

Down Arrow

Click on the Down arrowhead to expand the direction choices.

Left Arrow

Once the vertical line segment is started, you can change directions by clicking on another arrowhead.  This sample shows using the Left Arrow.

Continue the Line

Continue the line in this manner until you reach your destination. Then, select Reset Line Mode to return to normal editing. Now, you can add contacts to the new rung as needed.

Line Tool

Select the Line Tool to change the Edit Box into a Blue Arrow. The Blue Arrow will replace the Edit Box until you use Restore Line Mode to return to the Edit Box.

Note: While the Line Tool is in use, the cursor will toggle between a pencil cursor and a hand cursor . Hovering over the Blue Arrow will cause the pencil to change to a hand. While the hand cursor is visible, you can select any available Blue Arrow to extend the rung in the direction of the arrow.
