View Toolbar

Topic: CL125

Description

The dockable View Toolbar provides one-click access to the Zoom features of the View Menu. Select any of the icons on the View Toolbar below for more information about that particular tool. The icons appear grayed out if they are not currently available.

Toggle the View Toolbar On or Off

From View Menu > Toolbar, toggle any of the dockable One-click Toolbars Off or On.
