Help File Updates

This Help File is updated regularly with the intention of providing our Customers with the most complete and up-to-date information available on the use of the CLICK PLC Programming Software. Updated Help File Versions are posted on our web site within the CLICK Programming Software, which is available for download.

To check the Version of your Help File, open the Help File and the Title Bar (sample shown below) will show the Version of your Help File. Go to the CLICK Software Updates web site link provided below and compare your Software version with the latest one available on the web site. If a newer version is available, you may download the newer version and replace the older version. The download site provides instructions if needed.
