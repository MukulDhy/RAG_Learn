Battery Backup Setup

Topic: CL136

Description

This dialog allows you to let the CLICK CPU module know there is a Battery installed in the CPU module. The Standard and Analog CPU modules support this feature.

Setup

1Battery is not installed (SC203=OFF) / Battery installed (SC203=ON): The CLICK CPU module cannot detect if a Battery is installed. If a Battery is installed, please click the radio button for Battery installed (SC203=ON). You can refer to system control bit SC203 in the ladder program or from an external device connected to a Com Port to check if a Battery is installed.

Note: When a Battery is installed, the CLICK CPU module automatically uses it to backup the data in the SRAM even if the Battery Installed option is not selected. The main purpose of selecting the Battery installed option in this dialog is to Enable the Low Battery detection feature in the CPU module.

2Battery Replacement Notification: Check this option if you want the CLICK CPU module to indicate when the Battery life has passed the pre-defined date to replace it. The fields for the Battery Replacement Notification option will become active as shown below. To clear the Battery Replacement Notification the project file must be updated with a new replacement date and the project transferred to the PLC.

  

To use this feature correctly, please set the date when the New Battery is installed.  Enter the Date in the New battery was installed on field. Click the down arrow button in the right of the field to open the Calendar shown below for easy Date entry.

  

Next, enter the Date to Replace the Battery in the Anticipated replacement date field. If you installed a New Battery in the CLICK PLC, this Date can be Five Years after the installation Date.  You can set any other Date within Five Years after the installation Date.

To check if the Anticipated Date has passed using the ladder program or from an external device connected to a Com Port, refer to System Control Bit  SC29. The ERR light on the CPU module will start flickering when the Anticipated Date has passed.

3Low Battery Notification: When the Battery installed option is selected, the CLICK CPU module indicates the Low Battery when the Battery voltage is less than 2.5VDC. System Control Bit SC28 turns ON and the ERR light on the CPU module blinks. These Low Battery indications are disabled automatically when the Battery is replaced with a new one and the Battery voltage is more than 2.5VDC.
