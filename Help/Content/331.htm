Topic: CL331

Create Application Certificate Settings

Fill in all required information to create a self-signed Application Certificate. The purpose of the certificate is to enable Client devices to identify and validate the source of the data sent from an OPC UA server.

 

IP Address: The certificate is associated with the C2-OPCUA module's IP Address. The address is set on the previous screen, and is shown here for reference.

Domain Name: The certificate is associated with a particular Domain. For the C2-OPCUA module, the domain is fixed as "C2-OPCUA" and is shown here for reference.

Common Name: The certificate is associated with a particular Server Name. The name is set on the previous screen, and is shown here for reference.

Country: [Required] Enter a valid two letter country code (e.g., US).

Organization: [Required] Enter an organization name for the certificate. Max 64 characters. Certain special characters are not permitted, as noted below.

Organizational Unit, State, and Locality: [Optional] Enter additional organizational information if desired. Max 64 characters. Certain special characters are not permitted, as noted below.

Note:The following special characters are not allowed in the certificate fields: " # $ ( ) - ^ @ [ ; : ] , . / \ = ~ | ` { + * } < > ? _

Key Size: The default key size is 2048 bits. Optionally, this may be changed to 1024, 3072 or 4096 bit. We recommend leaving the default unless you understand the security and performance implications of changing the key size.

Signature Algorithm: The default signature algorithm is Sha 256. Optionally, this may be changed to Sha 1, Sha 224, Sha 384 or Sha 512. We recommend leaving the default unless you understand the security and performance implications of changing the signature algorithm.

Lifetime: Set a limit on the lifetime for the certificate to remain valid. A range between 1 day and 10 years may be selected. At then end of this time period, an administrator will need to reconnect to this server, generate a new certificate and re-install it into any clients connecting to this server.
