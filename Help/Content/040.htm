Line Erase

Topic: CL040

Line Erase Icon and Menu Selection Purpose

The Line Erase icon is located on the Edit Toolbar and the Line menu selection is available from the Edit Menu. The Edit Menu is located on the Main Menu, as shown on the figure below.  There is also a Keyboard Shortcut to activate the Line Erase Tool.

Select Line Erase

Select the Line Erase tool and point to any part of the line to be removed.

Remove Segments

Click on the portion of the line you want to remove.

Continue

Continue to remove the line, as necessary.

Switch to Line Tool

Now, you can switch from the Line Erase Tool to the Line Tool and reconnect the parallel rung midway between the X001 contact and the X002 contact. And, finally, select Reset Line Mode to return to normal editing.
