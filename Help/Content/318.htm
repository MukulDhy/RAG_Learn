CLICK PLUS Email Import Address Book

Import Email Address Book from CSV File

The Import Address Book feature allows the user to Import an external CSV file. This can be used to share these accounts from another project file, or for creating new addresses quickly by Export, Edit, and then Import back into the same project.

The CSV file is easily read and edited using Excelor Notepad.

File Path: Select the folder where you have the CSV file.

My file contains a Header Row: If the CSV file was created by Export it will contain a Header Row. Otherwise deselect this option.

Error if CSV is Open

If the CSV file is open in another program, you will receive an Error Message.

Maintain the Format

Failure to maintain the column data format, may result in Import Errors.
