Select I/O Module

Topic: CL141

Purpose

The Select an I/O Module dialog allows the selection of Slot I/O and Stackable I/O as part of the offline System Configuration.

Setup

To add or remove I/O modules the CLICK software must be Offline. If the software is Online with a PLC, the Select and Remove selections in the System Configuration dialog will be disabled.

Open the Select an I/O Module dialog by clicking on Select for the appropriate slot in the System Configuration dialog.

 

1Select I/O Category: Different categories are available based on the CPU selection and Slot selection. You can select from available categories to filter the I/O Module Type list.

Stackable I/O

  • Digital Input
  • Digital Output
  • Digital Input/Output
  • Analog Input
  • Analog Output
  • Analog Input/Output

Slot I/O

  • Digital Input & Output
  • Digital I/O & Analog I/O
  • Intelligent

2 Select I/O Module Type: Select the I/O Module by its Part Number.

3 I/O Detail Information: This section provides a brief list of specifications for the selected I/O module.

4 Description: Additional information about the selected I/O module.

5 Image of Module: Visual reference to confirm module selection.
