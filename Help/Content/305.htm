CLICK PLUS Email Simulate Dynamic Address

Topic: CL305

Description

With this dialog, you can assign test values to the Memory Addresses embedded in the Dynamic Email Address and check the result.

Dynamic

In this image the Email Address is configured as Dynamic. The Dynamic characters are contained in registers TXT1 to TXT21. The Dynamic characters contain the full address.


Dynamic address without Byte Swap


Dynamic address with Byte Swap

Address Preview: This field displays the Email Address that will be used by the Email Instruction.

Address Length: This is the number of Characters used in the Email Address displayed in the Address Preview field. The maximum length is 128.

Address List: All Memory Addresses used by the Dynamic portion in the Email Address are displayed in this list. You can assign a Simulation value to each Memory Address. The Email Address in the Address Preview field is updated automatically.

Dynamic + Static

In this image the Email Address is configured as Dynamic + Static. The Dynamic portion is contained in registers TXT1 to TXT5. The Static portion contains the domain name is constant, “example.com”. The ampersand ‘@’ character is automatically inserted.


Dynamic + Static address without Byte Swap


Dynamic + Static address with Byte Swap

Byte Swap

If Byte Swap is selected in the Edit Email Address dialog, the Register values of the Dynamic field will be Byte Swapped.
