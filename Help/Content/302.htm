Topic: CL302

CLICK PLUS Email Log

Description

This feature is enabled in the Email Setup Dialog using the option “Enable Email Troubleshooting”. The recent communications between the email Client and Server can be recorded into a small buffer. This Email Log can be displayed in the software while online by using Menu > PLC > Check Event Records > Email Log. With the C2-03CPU the Log can also be saved into a file on the SD Card by using Menu > PLC > SD Control Center.

It can be difficult to diagnose configuration problems with Email Servers. Since these communications may also be encrypted, it becomes an even greater challenge to identify an issue. The Log is a recording of the unencrypted data stream allowing it to be readable. This Log is not intended for historical records. It is 4,096 characters in total length. The Email Instruction returns Error Codes for all errors. The Error Log records the communications with the Server. If the Error Code is less than 04xx then the error is likely a setup or connection issue, no communications occurred, so no Email Log will be recorded.

Export: This allows the user to create an external raw text file of the Email Log currently displayed. This is useful when diagnosing a configuration error with your Network Administrator.

Clear: This will immediately clear both the currently displayed Log and the Log stored in the PLC.

Note: The Email Log in the PLC is not retentive; it will be cleared by a power cycle.
