Import

Topic: CL023

Description

The Import selection available from the File Menu, allows the users to Import existing files located on the user's PC, network, or disk. CLICK Programming Software allows the Import of an external CSV file of Nicknames.

The CSV file is easily read and edited using Excelor Notepad. Select File > Import > Nickname to open the Open dialog. (show appearance in Excel - show appearance in Notepad.)

In order to import a Nickname file, one must have been created and saved in the CSV file format. It is easy to edit a CSV file in Excel, but when the editing is done, be sure to save the file in the CSV format.

The Import selection is available from the File Menu selection on the Main Menu. When the user hovers the cursor over Import, the sub-menu item Nickname appears as a link to the Open dialog. The Open dialog allows access to Import a list of Nicknames. See Import Nicknames.
