Exit

Topic: CL029

Description

Select Exit from the File Menu to close the CLICK Programming Software application. If there is an open Project that has been saved in its current form, the software application will close. If there is no open Project when you click Exit, the software application will close.

Save Changes?

If the open Project has not been saved, you will be asked if you want to save the Project before exiting the software application. If you click Yes, the Projectwill be savedand the software application will close. If you click No, the software application will close without saving the Project. If you click Cancel, the Project will not be saved and the software application will not close.
