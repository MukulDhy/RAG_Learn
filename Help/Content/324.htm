Installing the Remote PLC App

The free Remote PLC App is available for iOS and Android devices on the Apple App Store and Google Play Store, respectively. Search for the app on the appropriate app store using the information below, or click the store link to install the app.

Using the Remote PLC App

Ensure the PLC is in Run Mode, if the PLC is in Stop Mode, you can view or set values, but they will not be applied to physical outputs.

When you open the Remote PLC App, you will be prompted to use Bluetooth (BLE) or Wi-Fi. Select the appropriate connection based on your configuration.

You will then see a list of CLICK PLCs found using that connection. Select the PLC you want. If you are not sure, you can tap the LED icon to make the PLC Run and Error LEDs blink in an alternating pattern.

Once you have identified the PLC, tap it to open the login screen for that PLC. Login with the Username and password you configured for your user in the Remote PLC User Setup dialog.

Once in Edit mode, you can make changes to one or more registers by tapping on the register and updating a value. Once you are ready to send your changes to the CLICK, tap the Write button in the top left of the screen. This will immediately send all changes tot he PLC.

From the Remote PLC Monitor editor, when you edit a field, it will turn yellow to indicate the value has been modified but NOT sent to the PLC. Once you click “Write” it will send all modified values to the PLC to be updated.

The gear in the top right corner allows you to view data type information and modify the view settings.

Troubleshooting Remote PLC Connections

Remote PLC ONLY works on a local network. You CANNOT use the Remote PLC App from outside your local network.

  • Ensure the CLICK PLC has an active network connection, and a good IP address.

  • Ensure your mobile device is on the same network.

  • Ensure you are within range of the Wi-Fi or Bluetooth signal.

Remote PLC will automatically log you out in the following conditions:

  • Phone enters sleep mode (Screen lock)

  • You change to a different network

  • You download a new CLICK program
