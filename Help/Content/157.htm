Completing a Rung

Topic: CL157

Extending a Rung

There are two reasons why a rung may become broken and need to be extended:

  1. Extend Broken Rungs where rung elements were Deleted
  2. Extend Horizontal Rungs where Resets, etc., are required by Coil Devices

Please look at the example below. It explains the rung completion using the Line Tool to complete a Reset rung for a Timer Instruction.

Attaching Reset Rungs

Certain Coil Area Devices require additional rung lines for Reset connections or for other purposes. These lines are easily added using the Line Tool.

Example:Timers that do not reset automatically, require an additional rung for the placement of the Reset Contact. In the example below, the Timer has just been placed in the rung and the Reset Rung must now be connected.

Place Edit Box

Using the Arrow Keys or the Cursor place the Edit Box at the same level as the Timer Reset line.

Line Tool

Select the Line Tool to change the Edit Box into a Blue Arrow. The Blue Arrow will replace the Edit Box until you use Restore Line Mode to return to the Edit Box.

Note: While the Line Tool is in use, the cursor will toggle between a pencil cursor and a hand cursor . Hovering over the Blue Arrow will cause the pencil to change to a hand. While the hand cursor is visible, you can select any available Blue Arrow to extend the rung in the direction of the arrow.

Connect Rung

Continue to extend the line until it joins the Reset Connection on the Timer.

Select Reset Line Mode

After adding the line, click on the Reset Line Mode icon or menu selection. Reset Line Mode closes the Line Tool and restores the Edit Box. You can now add contacts to the new rung, as necessary.
