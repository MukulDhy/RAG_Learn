Read Data From PLC

Topic: CL087

Description

Read Data Memory allows the user to extract discrete event or data values from the PLC in the form of a CSV file. Read Data Memory is available only when the PLC is Connected.

Open the Read Data dialog from the PLC Menu or the Navigation Window.

Setup

1a Select Read Memory Type: Click the check boxes to select the Memory Types that you want to read from the PLC memory.

1b All button: Click the All button if you want to save the current values of all Memory Types.

 

Note:System Memory values are not available, nor are the registers XD or YD, although the full range of X an Y memory addresses are accessed when you check those boxes.

2 Read button: Click the Read button to load the memory values from the PLC to the CSV file in the PC.

Saving the Project Data File

Name the CSV file and click Save.

CSV File Format

View or manipulate the data in Notepador Excel.
