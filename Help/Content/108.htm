C0-04RTD Settings

Topic: CL108

Description

The C0-04RTD Setting dialog supports the customer to select the RTD sensors to measure temperature and/or resistance input ranges, and assign DF memory addresses to store the analog input values.

1 Channels to Use: Enter the number of channels you actually use.

2 Unit: Select the temperature unit between C (Celsius) and F (Fahrenheit) for the RTD input type.

3 Input Type: Select an RTD sensor or resistive input range from the list.

Tip: If you are going to select a resistive input range and there are more than one range available, select the narrowest range to get more stable results with lower noises. For instance, you are going to measure 100 ohm, all of those 5 resistive input ranges can be used for the purpose. However, we recommend you to choose the range ‘0 to 195.31 ohm’ for the better results.

4Input Range: Enter the maximum and minimum Input Range to scale. (This option is available when you select a resistive input range as the Input Type.)

5 Scale Range: Enter the maximum and minimum scaled values. (This option is available when you select a resistive input range as the Input Type.)

In the following example, the Input Range is set to 0.0 – 3125.0Ω and the Scale Range is set to 0.0 - 100.0. This means input resistance 0.0Ω will be converted to 0.0 and input resistance 3125.0Ω will be converted to 100.0. When input resistance is 1562.5Ω, 50.0 will be put in DF1.

6 Enable Range Limiter: By checking this option, the analog values that are outside of the Input Range will be adjusted to the minimum or maximum value of the Scale Range. (This option is available when you select a resistive input range as the Input Type.)

1. Enable Range Limiter is ON.

2. Enable Range Limiter is OFF.

7 Continuous Address: If you want to assign continuous DF memory addresses to store the scaled analog input values, please check this option. In the case, you just need to assign a DF memory address to CH1. The DF memory address will be the starting address of those continuous DF memory addresses.

8Data Register: Enter a DF memory address to store the scaled analog value. In the CLICK PLC, all analog data are handled as floating point numbers. So you can select only DF memory addresses.

9Resolution: The CLICK software automatically calculates the resolution of the scaled data according to the bit resolution of the analog input and the scaling setup, and display the value here.

10 X bit Addresses: You can use these X bit addresses to monitor the status of this analog input module.
