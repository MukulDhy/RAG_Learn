CPU Built-in I/O Setup: Input Tab (Analog CPU)

Topic: CL208

Purpose

The CPU Built-in I/O Setup Input Tab dialog gives the user access to setup parameters that are available exclusively for the Built-inInputs. When the Built-inInput Tab is selected, the Input settings options are displayed as shown below.

1 General: Selecting the General Tab displays the CPU Built-in I/O General options. To learn more about the General Tab, click on the green text.

2 Output: Selecting the Output Tab displays the CPU Built-in , Output setup options. To learn more about the Output Tab setup, click on the green text.

3 Voltage/Current: Select the analog input type for AD1 and AD2.

Note: The CLICK analog CPU can not detect which input type is being used. Please select the proper input type in this dialog.

4Input Range: Enter the maximum and minimum Input Range to scale in the following ranges.

  1. Voltage Input Type: 0 – 5 VDC
  2. Current Input Type: 4 – 20 mA

Scale Range Example

5Scaled Range: Enter the maximum and minimum scaled values.

In the following example, the InputRange is set to 0.0 – 2.0VDC and the Scaled Range is set to 0.0 – 100.0. This means input voltage 0.0 VDC will be converted to 0.0 and input voltage 2.0 VDC will be converted to 100.0.  When input voltage 1.0 VDC, 50.0 will be put in DF1.

Enable Range Limiter Example

6Enable Range Limiter: By checking. this option, the analog values that are out side of the Input Range will be adjusted to the minimum or maximum value of the Scaled Range.

(1) Enable Range Limiter is ON.

(2) Enable Range Limiter is OFF.

7 Data Register: Enter a DF address to store the scaled analog value. In the CLICKPLC, all analog data are handled as floating point numbers. So you can select only DF Memory Addresses.

8 Resolution: The CLICK software automatically calculates the resolution of the scaled data according to the bit resolution of the analog input and the scaling setup, and display the value here.

9 Continuous Address: If you want to assign continuous DFMemory Addresses for AD1 and AD2, please check this option.
