Topic: CL013

Main Window

The Main Window is displayed when the program opens.  The MainWindow is divided into Menus, Toolbars, and Windows that work together to make project development as simple as possible.

Main Window Function

The Main Window is divided into Nine Functional Areas. To provide maximum flexibility for programmers, all Main Window features can be Turned Off except:

  • Title Bar
  • Main Menu
  • Ladder Editor

Nine Functional Areas

To learn more about a feature, click on the area where the arrow is pointing or where a circled number is displayed on the figure shown above, or click on a name from the list below.

  • Windows Title Bar
  • Main Menu
  • Dockable Toolbars
  • Hide/Show Buttons
  • Navigation Window
  • Ladder Editor
  • Instruction List  Window
  • Output Window
  • Status Bar
