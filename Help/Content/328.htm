Topic: CL328

Add/Edit Node-RED Account

You may configure up to 8 users who have either read-only or full access to modify Node-RED flows.

Node-RED Accounts do NOT apply to the Node-RED Dashboard, or the APIs created using nodes in the Network Group (e.g. “HTTP IN”, “TCP IN”, “HTTP REQUEST”).

 

You must enter both a user name and a password. Each must be at least 8 characters and up to 13 characters.

Note:The following special characters are not allowed: " ' ( ) + , - . / : ; < = > ? [ \ ] ^ _ ` { | } ~
