Export

Topic: CL024

Description

The Export selection is available from the File Menu selection on the Main Menu. When the user hovers the cursor over the Export selection, a sub-menu is displayed with the choices of Nickname or CLICK Loader File. Click on the item you would like to Export and a dialog will open to Export a Nickname or a CLICK Loader File.
