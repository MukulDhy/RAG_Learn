Connection Status

Topic: CL133

Description

The Connection Status Toolbar displays one of Four conditions:

  1. Offline: Indicates that the PLC is currently Disconnected from the PC.
  2. Stop: Indicates that the PLC Ladder Program is currently NOT Running.
  3. Run: Indicates that the PLC Ladder Program is currently Running.
  4. Error: Indicates that a PLC Error has occurred.

Click Offline to Open the Connect Dialog

The Connection Status Toolbar consists of a button that brings up a dialog. When the name on the button is Offline, click it to bring up the Connect to PLC dialog.

 

Click Stop to Open the Mode Dialog

When the name on the button is STOP, click it to bring up the PLC Modes dialog. The PLC Modes will be defaulted to RUN.  ClickOK to place the PLC in RUN Mode.

Click Run to Open the Mode Dialog

When the name on the button is RUN, click it to bring up the PLC Modes dialog. The PLC Modes will be defaulted to STOP.  Click OK to place the PLC in STOP Mode.

Toggle the Connection Status Toolbar On or Off

From View Menu > Toolbar, toggle any of the dockable One-click Toolbars Off or On. If there is a check beside the name of the Toolbar, then it is turned ON.
