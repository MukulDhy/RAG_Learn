Topic: CL311

Allow List Add/Edit IP Address

Description

There are four methods of adding an IP Address to the list:

  • Single IP
  • Range of IP (within a subnet)
  • Subnet (using Mask)
  • Subnet (Wild card)

 

Setup

Single IP: Each individual device IP can be specified.

Range of IP (within a subnet): An inclusive range of IP Addresses. The beginning and ending are specified arbitrarily.

Subnet (using Mask): An inclusive range of IP Addresses specified by the Subnet Mask. All valid subnet masks are supported in this mode.

Subnet (Wild card): An inclusive range of IP Addresses specified by a Wild card. Only Class B (255.255.0.0) or Class C (255.255.255.0) are supported in this mode.
