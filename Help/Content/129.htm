Monitor Toolbar

Topic: CL129

Description

The dockable Monitor Toolbar provides one-click access to the most commonly used tools on the Monitor Menu. Select either of the icons on the Monitor Toolbar below for more information about that particular tool. The icons appear grayed out if they are not currently available.

Toggle the Monitor Toolbar On or Off

From View Menu > Toolbar, toggle any of the dockable One-click Toolbars Off or On. If there is a check beside the name of the Toolbar, then it is turned on.
