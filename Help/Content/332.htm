Topic: CL332

Add/Edit OPCUA Account

You may configure up to 8 OPC UA Clients who have access to the OPC UA server.

 

You must enter both a user name and a password. The user name must be at least one character and the password must be between 8 characters and 13 characters.

Note:The following special characters are not allowed: " ' ( ) + , - . / : ; < = > ? [ \ ] ^ _ ` { | } ~
