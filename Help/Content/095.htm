What's New?

Topic: CL095

Readme File

The Readme file included with the CLICK Programming Software is a text file that provides information on What's New with the software version you are currently using, improvements, requirements, and other important and helpful information.

When the CLICK Programming Software is installed, a Readme file is included with the installation. This file is stored in the installation folder, which is "C:\Program Files (x86)\AutomationDirect\CLICK Ver3.80" by default.
