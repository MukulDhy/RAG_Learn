Export Nicknames to CSV File

The Export Nickname feature allows the user to create an external CSV file of:

  1. Address
  2. Data Types
  3. Nicknames
  4. Initial Values
  5. Retentive Status (Yes, No)
  6. Address Comments

The CSV file is easily read and edited using Excelor Notepad. Select File > Export > Nick Names to open the Save As dialog.

( show appearance in Excel - show appearance in Notepad)
